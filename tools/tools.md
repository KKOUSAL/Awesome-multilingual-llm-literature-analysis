# Tools

## 1. mT5

**Purpose:**  
mT5 is a multilingual variant of T5, trained on 101 languages. It also incorporates a new “accidental translation” technique to prevent the model from incorrectly translating predictions into the wrong language.

**Link:**  
https://huggingface.co/docs/transformers/en/model_doc/mt5


## 2. XLM-RoBERTa

**Purpose:**  
XLM-RoBERTa is a large multilingual masked language model trained on 2.5TB of filtered CommonCrawl data across 100 languages.

**Link:**  
https://huggingface.co/docs/transformers/en/model_doc/xlm-roberta


## 3. NLLB-200

**Purpose:**  
No Language Left Behind (NLLB) is a first-of-its-kind, AI breakthrough project that open-sources models capable of delivering evaluated, high-quality translations directly between 200 languages.

**Link:**  
https://ai.meta.com/research/no-language-left-behind/


## 4. SelfCheckGPT

**Purpose:** 
Zero-Resource Black-Box Hallucination Detection for Generative Large Language Models.

**Link:**  
https://github.com/potsawee/selfcheckgpt


## 5. spaCy (multilingual models)

**Purpose:**  
spaCy is a library for advanced Natural Language Processing in Python and Cython. It's built on the very latest research, and was designed from day one to be used in real products.

**Link:**  
https://github.com/explosion/spacy
